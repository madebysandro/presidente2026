# Agentes

- Workflow: issue antes do código; TDD; `npm test` + `npm run build`; PR com `Closes #N` e, no corpo, saída dos comandos mais o resumo do code-review.
- Produto: `presidente2026.win`, só Presidente nacional do 2º turno (eleição `6258`). O painel do 1º turno (`apuracao.madebysandro.app`) é outro repo e não muda aqui.
- Fidelidade visual (fase pesquisas): branch `prototipo/pesquisas`, commit `b1fe8ea`, direção A · Três semanas. Checklist em `docs/prototipo/README.md` quando a página entrar.
- Guardrail: barra rosa, variantes B/C do protótipo de pesquisas, Three.js, mascotes e confetti ficam de fora.
- Stack: Void (`void` + Vite). Config em `void.config.ts` / `void.lock.json`. Docs: https://void.cloud
- Deploy: produção só na `main`, via Cloudflare Workers Builds (sem workflow de deploy no GitHub). Build `npm run build`; deploy `npx void deploy --platform cloudflare` (`cloudflare.account_id` no `void.config.ts`; token do Builds = `CLOUDFLARE_API_TOKEN`). O modo em `void.config.ts` é `atomic`, temporário enquanto o Cloudflare APIError 100405 não tiver correção. A mensagem é `All versions in a multi-version deployment must declare identical exports`, issue voidzero-dev/void#460. O tráfego muda antes do readiness. O modo não reescreve as migrações de Durable Object em `void.lock.json`. Uma migração de classe pendente passa. Plano B se a versão no ar precisar voltar: `void project rollback` (código e triggers; o rollback ainda não cruza a fronteira da migração de classe de DO; rollback de banco também não desfaz migração) ou o dashboard da Cloudflare (Deployments da Worker). `void project logs` é o tail ao vivo. Root `/`; Node `24.21` (`.nvmrc`). Sem preview de branch. O Void 1.1.11 não desliga isso no `void.config.ts`. Não adicionar bloco `previews`. O interruptor é `previews_enabled` no Workers Builds. Detalhe dos cliques: README → Deploy.
- Models: `.cursor/rules/pstack-models.mdc` (gerado por `/setup-pstack`, budget medium / high).
