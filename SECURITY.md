# Segurança

Para reportar uma vulnerabilidade, abra um [aviso privado](https://github.com/madebysandro/presidente2026/security/advisories/new) neste repositório (GitHub Security Advisories).

Se o aviso privado não estiver disponível, escreva em particular para [@madebysandro](https://github.com/madebysandro). Não abra issue pública com o detalhe.
